A web-based culinary discovery platform that organizes fragmented local culinary-business information into an accessible digital database supporting culinary discovery and regional tourism promotion for Bandung City.

## Project Overview

Bandung Food Explorer is a mobile-friendly web application that helps users discover, explore, and compare local restaurants in Bandung City. The platform brings together authentic culinary experiences, making it easy for both locals and tourists to find their next favorite meal.

## Features

### Core Features
1. **Browse Food Places** - Explore restaurants around Bandung City
2. **Restaurant Details** - View menus, prices, and detailed information
3. **Comparison Tool** - Compare multiple restaurants side-by-side
4. **Food Discoveries** - Read about recent food finds and experiences
5. **Search Functionality** - Find restaurants by name, cuisine, or location

### Technical Features
- Responsive design (mobile-first approach)
- Interactive restaurant comparison
- Smooth animations and transitions
- Real-time search with debouncing
- Modal-based restaurant details
- Accessible navigation

## Getting Started



### Installation
1. Clone or download the project files
2. Open `index.html` in your web browser

### For Development
```bash
# Install dependencies
npm install

# Start local server
npm start
```
